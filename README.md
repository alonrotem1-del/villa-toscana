# וילה טוסקנה: אתר חדש

אתר סטטי (HTML/CSS/JS, בלי build). כל התמונות והמידע לקוחים מ־villa-toscana.co.il.

- `index.html`: דף הבית (קולקציות, אאוטלט, מזרקות, פרויקטים, אודות, ביקור)
- `price-list.html`: מחירון אינטראקטיבי, הדמיית מרפסת בקנה מידה אמיתי, קומפוזיציות, טרקוטה ומזרקות
- `assets/js/data.js`: **כל המחירים, המידות והדגמים במקום אחד**. כדי לעדכן מחיר, משנים רק כאן.
- `assets/js/visualizer.js`: הדמיית המרפסת (יחידת ציור = 1 ס״מ)
- `models/`: עמוד לכל דגם, נוצר אוטומטית מ־`data.js` (`node scripts/build-models.mjs`)
- `npm run qa`: בדיקות נגישות, שגיאות ותצוגה בנייד ובמחשב
- `CLAUDE.md`: כללי העיצוב והעבודה לסוכן

להרצה מקומית: `python3 -m http.server` בתיקייה הזו, ואז לפתוח את http://localhost:8000.
להעלאה: להעלות את כל התיקייה כמו שהיא לכל אחסון סטטי (Netlify, GitHub Pages, Vercel או השרת הקיים).
